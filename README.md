# بانزل زه — برنامه اندروید و ویندوز

این برنامه یک پوشش (WebView) برای نسخه‌ی تحت‌وب بانزل زه است که روی هاست شما نصب شده. همه‌ی داده‌ها و لایسنس روی سرور شما می‌ماند.

## بیلد روی GitHub
1. یک مخزن Private بسازید و همه‌ی فایل‌های این پوشه (از جمله `.github`) را در شاخه‌ی `main` آپلود کنید.
2. تب **Actions** → «Build Banzel» → **Run workflow** (یا با هر push خودکار اجرا می‌شود).
3. پس از پایان (۵–۱۰ دقیقه)، پایین صفحه‌ی همان اجرا در بخش **Artifacts**:
   - `banzel-android-apk` → فایل `app-release.apk` (روی گوشی نصب کنید؛ «نصب از منابع ناشناس» را مجاز کنید)
   - `banzel-windows` → کل پوشه را zip کنید/ببرید و `banzel_app.exe` را اجرا کنید (به Microsoft Edge WebView2 Runtime نیاز دارد؛ ویندوز ۱۱ و اکثر ویندوز ۱۰ از قبل دارند).
4. بار اول، آدرس سرور را وارد کنید (مثلاً `https://دامنه‌شما/banzel/`). با آیکون چرخ‌دنده بالای صفحه می‌توانید آدرس را تغییر دهید.
